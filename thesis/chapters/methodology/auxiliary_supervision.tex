\section{Auxiliary Supervision}
% Explain diagnostic, amyloid, and tau auxiliary tasks.
Mainly about adding classification and regression heads to predict diagnostic, amyloid, and tau levels to see if it improves reconstruction or the latent space. In detail:
\begin{itemize}
    \item Motivation for encouraging disease-relevant information in the latent space.
    \item Diagnostic classification head.
    \item HC/MCI/AD classification target.
    \item Classification-head architecture.
    \item Classification loss.
    \item Handling of class imbalance, if applicable.
    \item Amyloid-$\beta$ regression head.
    \item Tau regression head.
    \item Whether biomarkers are predicted region-wise or globally.
    \item Biomarker target preprocessing/normalisation, dealing with missing data.
    \item Regression loss.
    \item Combined multi-task objective.
    \item Weighting between reconstruction, classification and regression losses.
    \item Which parts of the network receive gradients from auxiliary tasks.
\end{itemize}
