\begin{itemize}
    \item Motivation for separating shared representation learning from disease-specific decoding.

    \item HC-specific decoder $D_{HC}$, MCI-specific decoder $D_{MCI}$, AD-specific decoder $D_{AD}$
    \item Use of the same latent representation for every decoder.
    \item Which components are frozen during class-specific decoder training.
    \item Initialization of class-specific decoders (e.g. from the general decoder, if applicable).
    \item Training data used for each decoder.
    \item Loss used to train the class-specific decoders.
    \item Interpretation of decoder differences as disease/class-specific mappings rather than differences caused by separate encoders.
    \item Application of target-class decoders to longitudinal data.
    \item Earlier scan as input and later scan as the longitudinal target.
    \item HC→MCI, MCI→AD, etc. transitions.
\end{itemize}
